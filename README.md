# BAEQ Portfolio

Bryan Aldrin Quinalayo's single-viewport portfolio, built with Next.js 16, React 19, and the App Router.

## Getting started

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000). Useful checks:

```bash
yarn test   # unit tests
yarn lint   # ESLint
yarn build  # production build
```

The primary experience lives in `src/app/(portfolio)`. The preserved cinematic version is available at `/star-wars`.
